INSIGHT
관찰과 발화가 같은 지점을 가리켰습니다. 참여자들은 상품이 마음에 안 든 것이 아니라, 자신의 상황에 가능할지 의문이었습니다. 이미 있던 탭과 필터가 아닌, 상품을 인지하고 판단하게 하는 장치가 필요하다는 인사이트를 얻었습니다.

종료 직후 구두 인터뷰에서 반복된 질문으로, 인터뷰 당시의 기록 노트를 기준으로 재구성한 표현입니다.

05 · REDEFINE

부분시공 상품이 부족한 것이 아니라, 사용자가 스스로 판단할 기준이 없었습니다

부분시공 상품을 추가해도 문의 35건 중 33건이 여전히 전화로 유입됐습니다. UT와 VOC를 교차 검증해 문제를 상품 부족에서 판단 기준의 부재로 재정의했습니다.

AS-IS · 프로젝트 전
서비스 접속→ 포트폴리오 탐색→ 부분시공 가능 여부 판단 불가→ 상담 전화→ 담당자 부재·대기→ 이탈
TO-BE · 최종
서비스 접속→ 부분시공 탭 진입→ 시공범위 선택→ 판단에 필요한 정보 확인→ 견적 신청
HYPOTHESIS
사용자가 시공 상담 이전에 스스로 가늠할 수 있는 판단 정보와 선택 기준을 제공하는 방향으로 문제를 재정의했습니다. 상담 단계에서 발생하던 판단을 탐색 단계로 이동하면 전화 문의가 줄어들 것이라는 가설을 세웠습니다.

부분시공 탭과 시공범위 필터는 1차 개편에서 이미 추가된 상태였습니다. 재정의를 통해 경로 자체가 아닌 가치 인지와 판단 정보를 보완했습니다.

06 · SOLUTION STEP 01 — 가치 인지 설계

사용자가 전화하지 않고도 우리집에 가능한 공사를 판단할 수 있게 만들었습니다

탐색을 시작하기 전에 필요한 가치와 판단 기준을 먼저 제공했습니다. UT에서 부분시공 개념 인지 자체가 부족했기에 가치 인지 단계를 뺄 수 없었습니다.

진입 배너 → 가치 인지 → 선택 기준 제시 → 판단 돕기 → 탐색 시작 · 출시 반영
07 · SOLUTION STEP 02 — 탐색 구조 설계

상담에서 확인하던 정보를 탐색 과정에 먼저 제공했습니다

사용자가 원하는 시공 범위를 직접 선택하고, 부분시공 상품과 상세 정보를 탐색할 수 있도록 탐색 구조와 콘텐츠를 새롭게 설계했습니다.

1

원하는 시공 범위를 먼저 선택

시공범위 필터를 추가해 전체 리모델링이 아닌 원하는 공사만 탐색할 수 있도록 했습니다

2

부분시공 전용 탐색 경로 제공

전체시공과 분리된 부분시공 탭을 추가해 원하는 상품군으로 바로 진입할 수 있도록 설계했습니다

3

판단에 필요한 정보를 한 화면에

공간 컨셉, 자재 정보, 실제 시공 사진을 함께 제공하여 상담 없이도 비교하고 선택할 수 있는 기준을 만들었습니다

CHANGED
탐색 단계는 늘렸지만, 판단에 필요한 정보는 앞당겼습니다.
08 · STATE DESIGN

조건이 적용됐는지를 화면이 답할 수 있도록

필터 적용 상태를 별도 장치로 알리는 대신, 결과 수 버튼의 변화(0개 비활성 → 7개 활성)가 상태를 말하도록 설계했습니다. 선택 없이 빈 결과에 도달하지 않게 하고, 선택 즉시 결과 수로 응답하는 구조입니다.

개발 반영 기준 — 개발사가 동일한 판단으로 구현할 수 있도록 상태를 명세로 정의했습니다.
